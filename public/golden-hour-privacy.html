Privacy Policy

Effective date: October 19, 2026

Golden Hour Finder helps users view golden hour, blue hour, sunrise, and sunset times for a location. This policy describes the information the extension uses to provide that feature.

Information the extension uses

  • A Google Maps URL from the active tab, when the active tab is a Google Maps location. The extension reads coordinates and an available place name from the URL; it does not read page contents.
  • Device location, when the browser provides it for the location feature. If there is no usable Google Maps location or saved location, the extension may ask the browser for permission to use the device location.
  • The selected location is saved in Chrome's local extension storage so it can be reused when the popup opens again.

Reverse geocoding

When device location is used, the extension may send the device coordinates to OpenStreetMap's Nominatim reverse-geocoding service to obtain an approximate city or locality name. The extension does not send coordinates for Google Maps locations to this service.

The reverse-geocoded place name is used to show an approximate locality in the popup. Nominatim's use is subject to the OpenStreetMap Foundation Nominatim usage policy . OpenStreetMap and Nominatim are independent services and are not used to create an account, profile, or location history for the user.

What the extension does not do

Golden Hour Finder does not:

  • Create user accounts.
  • Sell location information.
  • Use advertising or analytics trackers.
  • Collect browsing history.
  • Transmit location data to a service other than the optional reverse-geocoding request described above.

Local storage and deletion

The last selected location remains in Chrome's extension storage. Users can remove it by clearing the extension's site data in Chrome or uninstalling the extension. The extension does not maintain a server-side account or location history. Reverse-geocoding requests are used only to obtain the locality name and are not used by Golden Hour Finder to build a user profile.
